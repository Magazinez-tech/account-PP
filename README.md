# ระบบบัญชีบริษัท

ระบบจัดการลูกค้า ใบเสนอราคา ใบกำกับภาษี/ใบแจ้งหนี้ ใบเสร็จรับเงิน สมุดรายวัน งบการเงิน และภ.พ.30 สำหรับบริษัทที่จด VAT แล้ว

## เทคโนโลยี
- Frontend: React + Vite (ไฟล์ static ใน `dist/`)
- Backend: Express ทำงานเป็น Netlify Function ที่ `netlify/functions/api.js`
- ฐานข้อมูล: PostgreSQL บน Supabase
- การเก็บเงิน: เป็นสตางค์ (จำนวนเต็ม) เพื่อไม่ให้ทศนิยมคลาดเคลื่อน

## ตัวแปรสภาพแวดล้อม

| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `DATABASE_URL` | Connection string ของ Supabase (Transaction pooler) ห้ามใส่ในโค้ดหรือ commit |
| `DATABASE_SSL` | ค่าเริ่มต้นเป็นเปิด SSL ตั้งเป็น `false` เฉพาะฐานข้อมูลทดสอบในเครื่อง |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `ADMIN_NAME` | ผู้ดูแลคนแรก สร้างเมื่อยังไม่มีผู้ใช้ในฐานข้อมูล |
| `NODE_ENV` | ตั้งเป็น `production` บน Netlify เพื่อให้ cookie แบบ Secure |
| `PORT` | พอร์ตของเซิร์ฟเวอร์ในเครื่อง (ค่าเริ่มต้น 3000) |

## รันในเครื่อง

```bash
npm install
# PowerShell
$env:DATABASE_URL="postgres://..."; $env:ADMIN_EMAIL="you@company.com"; $env:ADMIN_PASSWORD="..."
npm run dev
```

- หน้าเว็บ: `http://localhost:5173`
- API: `http://localhost:3000/api`

## ติดตั้งบน Netlify + Supabase
1. สร้างโปรเจกต์ Supabase แล้วคัดลอก connection string แบบ Transaction pooler
2. เชื่อม repo `Magazinez-tech/account-PP` กับ Netlify (ไฟล์ `netlify.toml` ตั้ง build และ redirect ไว้แล้ว)
3. ตั้งตัวแปรสภาพแวดล้อมบน Netlify ได้แก่ `DATABASE_URL`, `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `NODE_ENV=production`
4. Deploy แล้วเข้าสู่ระบบด้วยผู้ดูแลที่ตั้งไว้ ตารางจะถูกสร้างอัตโนมัติตอนเริ่มทำงานครั้งแรก

ตารางทั้งหมดเปิด Row Level Security ไว้ เพื่อไม่ให้ใครเข้าถึงข้อมูลผ่าน API สาธารณะของ Supabase ด้วย anon key เซิร์ฟเวอร์ใช้สิทธิ์เจ้าของตารางจึงยังเข้าถึงได้ตามปกติ

## การพิมพ์และ PDF
ใช้ปุ่ม **พิมพ์ / บันทึกเป็น PDF** ของเบราว์เซอร์ เลือกต้นฉบับ สำเนา หรือทั้งสองชุดก่อนพิมพ์

## กฎสำคัญ
- เลขที่ใบเสนอราคา `PP-MM-NNNN` (MM เดือนของวันที่ออก นับใหม่ทุกเดือน)
- เลขที่ใบกำกับภาษี `INV-ปี-NNNN` และใบเสร็จ `RC-ปี-NNNN` ไม่ซ้ำและไม่ข้าม
- ไม่สามารถลบเอกสารที่ออกเลขแล้ว ยกเลิกแทนได้เฉพาะที่ยังไม่มีการรับชำระ
- วันครบกำหนด = วันที่ออกใบกำกับภาษี + เครดิตลูกค้า (แก้ได้ แต่ต้องไม่ก่อนวันที่ออก)
- VAT 7% คำนวณจากยอดหลังหักส่วนลด ใบเสร็จแยก VAT ตามสัดส่วนของใบกำกับภาษี
- ทุกการออกใบกำกับภาษี รับชำระ และค่าใช้จ่าย ลงบัญชีคู่อัตโนมัติ การกลับรายการจะสร้างรายการใหม่ ไม่ลบรายการเดิม
