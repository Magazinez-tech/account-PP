# ระบบบัญชีบริษัท (MVP)

ระบบจัดการลูกค้า ใบเสนอราคา ใบกำกับภาษี การรับชำระเงิน และรายงานลูกหนี้ สำหรับบริษัทที่จด VAT แล้ว

## เทคโนโลยี
- Backend: Node.js + Express + SQLite (`node:sqlite` ในตัว ไม่ต้องติดตั้งเพิ่ม)
- Frontend: React + Vite
- ข้อมูลเงินเก็บเป็นสตางค์ (จำนวนเต็ม) เพื่อไม่ให้มีเศษทศนิยมคลาดเคลื่อน

## การติดตั้งและรัน

ต้องใช้ Node.js 22.13 ขึ้นไป (แนะนำ 24)

```bash
npm install
```

สร้างผู้ดูแลระบบคนแรก (ทำครั้งเดียว ตอนที่ยังไม่มีผู้ใช้ในฐานข้อมูล):

```bash
# Windows PowerShell
$env:ADMIN_EMAIL="you@company.com"; $env:ADMIN_PASSWORD="รหัสผ่านที่แข็งแรง"; $env:ADMIN_NAME="ชื่อของคุณ"
```

รันโหมดพัฒนา (API พอร์ต 3000 หน้าเว็บพอร์ต 5173):

```bash
npm run dev
```

รันโหมดใช้งานจริง:

```bash
npm run build
npm start
```

เปิด `http://localhost:3000` (ตัวแปรที่ตั้งได้: `PORT`, `DB_PATH`)

ฐานข้อมูลอยู่ที่ `data/app.db` ต้องสำรองไฟล์นี้เป็นประจำ

## ขั้นตอนทางธุรกิจ

1. **ลูกค้า**: บันทึกชื่อ เลขผู้เสียภาษี สาขา ที่อยู่ และเครดิต
2. **ใบเสนอราคา**: สร้างร่าง → ทำเครื่องหมายว่าส่งแล้ว → อนุมัติ/ปฏิเสธ → แปลงเป็นใบกำกับภาษี
3. **ใบกำกับภาษี**: สร้างร่าง → **ออกเอกสาร** (ได้เลขที่ `INV-ปี-เลข 4 หลัก` ต่อเนื่องไม่ซ้ำ และแก้ไขไม่ได้อีก)
4. **รับชำระ**: บันทึกการรับเงินทีละส่วนได้ ระบบออกเลขที่ใบเสร็จ `RC-ปี-เลข` ให้อัตโนมัติ เมื่อชำระครบสถานะจะเป็น "ชำระครบแล้ว"
5. **ยกเลิก**: ยกเลิกได้เฉพาะใบที่ยังไม่มีการรับชำระ เลขที่เดิมยังคงอยู่ในระบบ

## กฎที่บังคับในระบบ
- ไม่สามารถลบเอกสารที่ออกเลขที่แล้วได้ (ลบได้เฉพาะร่าง)
- ไม่สามารถลบลูกค้าที่มีเอกสารแล้ว
- ไม่สามารถรับชำระเกินยอดคงค้าง
- วันครบกำหนดชำระ = วันที่ออกใบกำกับภาษี + เครดิตของลูกค้า (แก้ไขได้ทั้งตอนเป็นร่างและหลังออกเอกสารแล้ว แต่ต้องไม่ก่อนวันที่ออกใบ)
- ภาษีมูลค่าเพิ่ม 7% คำนวณจากยอดหลังหักส่วนลด (ราคาที่กรอกเป็นราคาไม่รวม VAT)
- ทุก API ต้องเข้าสู่ระบบก่อน

## ยังไม่ได้ทำ (ขั้นถัดไป)
- ข้อมูลบริษัทสำหรับหัวใบกำกับภาษี (ชื่อ ที่อยู่ เลขผู้เสียภาษี โลโก้) และหน้าตั้งค่า
- ผู้ใช้หลายคนและการกำหนดสิทธิ์ตามบทบาท
- บันทึกประวัติการแก้ไข (audit log)
- ส่งออก PDF และส่งอีเมล (ตอนนี้ใช้ปุ่มพิมพ์ของเบราว์เซอร์)
- ใบลดหนี้/ใบเพิ่มหนี้ และรายงานภ.พ.30
- สำรองข้อมูลอัตโนมัติ และ HTTPS เมื่อนำขึ้นอินเทอร์เน็ต
- ย้ายไป PostgreSQL เมื่อมีผู้ใช้พร้อมกันจำนวนมาก
